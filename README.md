# Ritvik Pendyala — Portfolio

Personal portfolio site. Dark, type-led single page built on Astro + Tailwind.

## Stack

- **Astro** — static output, zero framework runtime
- **Tailwind CSS v3** — design tokens in `tailwind.config.cjs`
- **Vanilla JS** — scroll reveal, scroll spy, project filters, role rotator (no client framework)

## Content

All copy lives in one place: **`src/data/site.ts`** — profile, stats, education, experience,
projects, skills, achievements, interests. Edit that file to update the site; components read
from it and never hardcode content.

### Adding a project

Append an entry to the `projects` array. Every project automatically gets its own page at
`/projects/<slug>`, generated by `src/pages/projects/[slug].astro`.

| Field | Purpose |
| :--- | :--- |
| `slug` | URL segment — becomes `/projects/<slug>` |
| `blurb` | One-liner used on cards and as the page meta description |
| `cover` | Path under `public/images/`, or `null` for the generated monogram fallback |
| `overview` | Array of paragraphs for the detail page |
| `highlights` | `{ title, body }[]` — the "What I built" list |
| `stackDetail` | Optional grouped breakdown shown in the detail sidebar |
| `role`, `context` | Shown in the detail meta panel |
| `team` | Collaborators; also switches the heading to "What we built" |
| `results` | Optional `{label, value, note}[]` — renders a results table on the detail page |
| `featured` | `true` promotes it into the three-card row on the homepage |

Cover images are all 1748×1240 (ratio 1.41), and every frame uses `aspect-[7/5]` to match, so
nothing gets cropped. Keep new covers at that ratio. Filter categories are derived from the
project data, so a filter can never render an empty grid.

The résumé PDF is served from `public/RitvikPendyala_Resume.pdf` and linked from the nav, hero,
about, and footer.

## Structure

```
src/
├── data/site.ts                   # all site content
├── layouts/Layout.astro           # shell, design system, global scripts
├── components/
│   ├── elements/                  # Navbar, Footer
│   ├── sections/                  # Hero, About, Experience, Projects, Skills, Beyond, Contact
│   └── shared/                    # Container, SectionHeading, Social, ProjectCover, Pill
└── pages/
    ├── index.astro                # homepage
    └── projects/[slug].astro      # one page per project, from the projects array
```

## Commands

| Command           | Action                                      |
| :---------------- | :------------------------------------------ |
| `npm install`     | Install dependencies                        |
| `npm run dev`     | Dev server at `localhost:3000`              |
| `npm run build`   | Build production site to `./dist/`          |
| `npm run preview` | Preview the build locally                   |

## Notes

- The contact form posts to getform.io (endpoint in `src/components/sections/Contact.astro`).
- Content animates in on scroll via `[data-reveal]`. A `<noscript>` block and a 2s safety-net
  timeout in `Layout.astro` guarantee content is never left stuck at `opacity: 0` if JS fails.
- Soundboard and Huddl have no cover art yet and use the generated monogram fallback. Drop a
  1748×1240 image into `public/images/` and set `cover` to use a real one.
- `public/images/` also still holds icon assets from the previous design that nothing references.
